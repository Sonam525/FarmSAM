# Per-sequence scores

These are the stored outputs of the runs, at full precision, behind the tables in [docs/RESULTS.md](../../docs/RESULTS.md).

| Folder | Holds |
|:---|:---|
| `calf/` | Calf windows: by window, by phase, and the paired bootstrap against SAM 3 |
| `edinburgh/` | Edinburgh test clips, seeded from reference boxes |
| `pigtrack/` | PigTrack test sequences, seeded from reference boxes, with paired differences |
| `rfdetr_edinburgh/` | Edinburgh test clips with an RF-DETR detector |
| `rfdetr_pigtrack/` | PigTrack test sequences with an RF-DETR detector, with paired differences |
| `efficiency/` | Parameters, GFLOPs, latency and memory |
