# Distillation code

Teacher targets, student training and frame mining, in one flat folder. Scripts import each other by file name. The order of the steps is in [docs/REPRODUCE.md](../docs/REPRODUCE.md).

Two files start with `Tol_02b_`: one is the calf fidelity report, the other trains the PigTrack students. Use their full names.

These are Databricks source-format notebooks. Some keep the storage paths they ran with. Those paths are not secrets. Change them to yours.
