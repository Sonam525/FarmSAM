# Benchmark code

Each folder is one code set, kept flat as it ran. Scripts import each other by file name and many are recorded by hash, so do not move or mix files. [`CODE_MANIFEST.csv`](CODE_MANIFEST.csv) lists every file, its role and SHA-256. The steps are in [docs/REPRODUCE.md](../docs/REPRODUCE.md).

Five entries in the manifest are marked "not in this draft". They are the scorer, the calf window selection, one helper and the core's tests.
